# План-Проект: Location Joystick (Воссоздание на Flutter)

## 1. Общее Описание

Этот документ описывает детальный план по воссозданию нативного Android-приложения "Location Joystick" с использованием фреймворка Flutter. Цель — полностью повторить ключевую функциональность и логику оригинального приложения, но уже на современной кодовой базе Dart/Flutter, что обеспечит кроссплатформенность (как минимум для Android и iOS) и упростит дальнейшую разработку.

Оригинальное приложение — это инструмент для симуляции GPS-местоположения устройства с помощью экранного джойстика, который может отображаться поверх других приложений.

## 2. Детальный План Функциональности

На основе анализа исходного кода (в частности, файла `LjNavHost.kt`) и общей структуры, новое приложение будет включать следующие модули и экраны:

### 2.1. Первоначальная Настройка и Разрешения (Onboarding)
- **Цель:** Провести пользователя через процесс получения всех необходимых разрешений перед использованием приложения.
- **Экраны:** Пошаговый "мастер настройки", который будет запрашивать каждое разрешение отдельно.
- **Запрашиваемые разрешения:**
  - `ACCESS_FINE_LOCATION` (Доступ к точной геолокации): Необходимо для определения стартового местоположения и корректной работы карты.
  - `SYSTEM_ALERT_WINDOW` (Отображение поверх других окон): Критически важно для отображения плавающего джойстика.
  - `ACCESS_MOCK_LOCATION` (Подмена местоположения): Ядро функциональности, позволяющее приложению передавать системе фиктивные GPS-координаты.
- **Логика:** Приложение будет проверять наличие разрешений при запуске. Если все разрешения предоставлены, этот шаг пропускается, и открывается главный экран. В противном случае запускается экран настройки, который объясняет, зачем нужно каждое разрешение, и предоставляет кнопки для перехода в системные настройки.

### 2.2. Главный Экран и Навигация
- **Главный экран (`IdleScreen`):** Будет служить центральным хабом, откуда можно попасть в любой раздел. На нем будут расположены крупные, понятные иконки-кнопки:
  - "Карта"
  - "Маршруты"
  - "Избранное"
  - "Настройки"
  - "Синхронизация с группой"
- **Боковое навигационное меню (Navigation Drawer):** Основной способ навигации по приложению. Меню будет доступно со всех основных экранов и позволит быстро переключаться между разделами.

### 2.3. Экран Карты
- **Технологии:** Будет использован пакет `flutter_map` с плитками (tiles) от OpenStreetMap, что является отличной бесплатной альтернативой Google Maps и идейно близко к MapLibre из оригинального проекта.
- **Элементы интерфейса:**
  - Маркер, отображающий текущее (или симулируемое) положение пользователя.
  - Кнопки для масштабирования (+/-), центрирования карты на пользователе и смены слоев (например, "схема", "спутник").
  - Плавающая кнопка действия (FAB) для быстрого запуска джойстика.
- **Интерактивность:** Долгое нажатие на карту будет вызывать контекстное меню с опциями: "Начать движение сюда", "Добавить в избранное", "Проложить маршрут до этой точки".

### 2.4. Экранный Джойстик (Overlay)
- **Реализация:** С помощью пакета `flutter_overlay_window` будет создано плавающее окно, которое не зависит от основного приложения.
- **Функционал:** Перемещение джойстика будет в реальном времени обновлять фиктивное местоположение системы. Рядом с джойстиком будет отображаться текущая скорость симуляции.

### 2.5. Управление Маршрутами
- **Экран "Список маршрутов":** Отображение всех сохраненных маршрутов с указанием названия, дистанции и даты. Возможность смахнуть для удаления.
- **Функция "Импорт GPX":** Кнопка, открывающая системный файловый менеджер для выбора `.gpx` файла. После выбора файл будет распарсен, и его трек будет сохранен как новый маршрут.
- **Экран "Создание маршрута":**
  - Интерактивная карта, на которой пользователь касаниями расставляет точки (waypoints).
  - Возможность переключать режим прокладки пути между точками: "напрямую" или "по дорогам" (с использованием внешнего API, например, OSRM).
  - По завершении — диалоговое окно для ввода названия маршрута и его сохранения.
- **Экран "Детали маршрута":**
  - Карта с отрисованным треком маршрута.
  - Кнопка "Старт" для запуска симуляции движения по этому маршруту.
  - Настройки воспроизведения: выбор профиля скорости, режим (один раз, по кругу, "пинг-понг").

### 2.6. Управление Избранным
- **Экран "Список избранного":** Простой список сохраненных локаций.
- **Экран "Выбор на карте" (`MapPicker`):** Карта, на которой можно выбрать точку и сохранить ее с заданным именем. Будет также поле поиска для поиска локации по адресу (с помощью геокодинга Nominatim).

### 2.7. Настройки
- **Цель:** Предоставить пользователю полный контроль над всеми аспектами приложения.
- **Разделы настроек:**
  - **Профили скорости:** Пользователь может создавать, редактировать и удалять профили (например, "Пешком": 5 км/ч, "На машине": 60 км/ч).
  - **Джойстик:** Настройка размера, прозрачности, стиля.
  - **GPS:** Настройка точности (добавление случайного "шума" к координатам), высоты.
  - **Внешний вид:** Выбор темы (светлая/темная/системная).
  - **Управление данными:** Кнопки для "Экспорта" (сохранить все маршруты и избранное в один JSON-файл) и "Импорта" (восстановить данные из такого файла).
