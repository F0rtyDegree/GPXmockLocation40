Это приложение для проигрывания GPX-маршрутов.
Основные блоки:
Запуск: При старте открывается главный экран — RoutesScreen.
Главный экран (RoutesScreen): Здесь отображается список всех импортированных ранее маршрутов. Маршруты хранятся локально на устройстве.
Импорт: На главном экране есть кнопка "плюс", которая позволяет пользователю выбрать и импортировать .gpx файл из памяти устройства.
Обработка: После импорта приложение читает файл, извлекает из него точки трека, вычисляет для каждой точки курс (направление движения), просит пользователя дать маршруту имя и сохраняет его.
Просмотр на карте: Пользователь может нажать на любой маршрут в списке, и он откроется на экране с картой (MapScreen) для визуального просмотра.
Удаление: Маршруты можно удалять из списка.
